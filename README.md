# NetworkClient iOS

This repository is a public source snapshot of an iOS network client.

## Snapshot scope

The snapshot contains generic application, Network Extension, test, localization, privacy-manifest, and public placeholder configuration sources.

It does not contain production configuration, signing material, private branding, production API or remote-configuration endpoints, the prebuilt Mihomo XCFramework, or shipping GeoData databases.

The omitted runtime dependencies must be obtained, built, and redistributed only from sources and under terms that the user is authorized to use. This snapshot does not promise an out-of-the-box build.
